# Four-minute walkthrough script

1. Create a kit using the realistic Senior Full-Stack / Developer Experience job description and `https://about.gitlab.com` with five days.
2. Explain the sequence: company crawl, requirements, category-specific generation, deterministic coverage, and schedule allocation.
3. Show Brief sources and honest research warnings where a source is unavailable.
4. Edit and reorder a question, then regenerate a category to demonstrate edited/pinned state protection.
5. Reveal a flashcard answer, rate confidence, then open Weak spots to show confidence-weighted ordering.
6. Show the exactly five-day schedule and the earlier placement of must-have material.
7. Run `npm run evaluate -- --input examples/demo-case.json --output kits.json` to show the same pipeline running outside the UI.
